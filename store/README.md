# Play Store listing

Graphics for Campfire's store listing, matching Play Console's **Main store listing → Graphics**:

| File or folder | Play Console field | Size |
|---|---|---|
| `Campfire icon.png` | App icon | 512 × 512 (Play rounds the corners) |
| `Campfire feature graphic.png` | Feature graphic | 1024 × 500 |
| `phone/` | Phone screenshots | 1440 × 2560 |
| `tablet-7/` | 7-inch tablet screenshots | 1440 × 2560 |
| `tablet-10/` | 10-inch tablet screenshots | 2560 × 1440 |
| `chromebook/` | Chromebook screenshots | 2560 × 1440 |

Screenshots are named for their app and device, and numbered in the order to upload them. The screens inside the frames are drawn by the app's
own code (`ScreensTest`, which also renders the tablet sizes into `app/build/screens/`).

## Videos

- `videos/Campfire FOREGROUND_SERVICE_REMOTE_MESSAGING.mp4`: the remote messaging foreground service declaration (the chat server).
- `videos/Campfire promo.mp4`: the promo video for the store listing (Main store listing → Video), with original music. The rooms, people and messages in it are made up, drawn by the app's own screens.
